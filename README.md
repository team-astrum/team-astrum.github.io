# Cruscotto di progetto SWE

- `npm install && npm run dev` per sviluppare in locale.
- Aggiorna **solo `src/data.js`**: membri, ore, milestone, periodi EVM, elenco documenti.
- Scrivi i documenti in `docs/<BASELINE>/nome.typ`: la GitHub Action li compila in `public/docs/<BASELINE>/nome.pdf`.
- Su GitHub: Settings → Pages → Source: **GitHub Actions**.
